# OpenRouter Cast

Скрипт автоматически формирует markdown-таблицу **текстовых** моделей с платформы
[OpenRouter](https://openrouter.ai), отсортированную по цене output, с ценами
input/output в USD за 1 млн токенов и краткой оценкой пригодности модели для
диалога и ответов на вопросы.

Результат: [`openrouter_models.md`](openrouter_models.md).

## Что делает `generate.py`

1. Тянет актуальный список моделей с `https://openrouter.ai/api/v1/models`.
2. Отбирает модели, у которых выход **как минимум содержит текст**
   (в `output_modalities` есть `"text"`) — то есть и чисто текстовые,
   и мультимодальные модели с текстовым выводом.
3. Форматирует цены `input`/`output` в **USD за 1 млн токенов**.
4. Сортирует по цене **output** по возрастанию.
5. Пишет результат в `openrouter_models.md`.

> **Новые модели OpenRouter попадают в список автоматически** — для них
> используется эвристическое описание (`default_note`), пока вручную
> не добавлена детальная оценка в словарь `NOTES`.

## Локальный запуск

```bash
python3 generate.py
```

## Непрерывная интеграция (GitHub Actions)

В [`/.github/workflows/weekly.yml`](.github/workflows/weekly.yml) настроен
**еженедельный** запуск (по расписанию, каждый понедельник в 03:00 UTC,
а также ручной через `workflow_dispatch`). Workflow:

1. обновляет зависимости/окружение Python,
2. запускает `generate.py`,
3. коммитит изменения в `openrouter_models.md` и пушит их обратно в репозиторий.
