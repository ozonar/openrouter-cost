# OpenRouter Cast

Скрипт автоматически формирует markdown-таблицу разложенных по категориям моделей с платформы
[OpenRouter](https://openrouter.ai), 

Для каждой категории формируется отдельный markdown-файл.

## Категории моделей

| Файл | Категория | Что это |
|---|---|---|
| [`README.text.md`](README.text.md) | Текст | Чат, ответы на вопросы, работа с документами |
| [`README.image.md`](README.image.md) | Генерация изображений | Рисование и редактирование картинок |
| [`README.embeddings.md`](README.embeddings.md) | Эмбеддинги | Векторные представления текста |
| [`README.video.md`](README.video.md) | Генерация видео | Видео из текста/изображений |
| [`README.audio.md`](README.audio.md) | Генерация музыки | Создание музыки/звука |
| [`README.rerank.md`](README.rerank.md) | Реранкинг | Переупорядочивание документов |
| [`README.speech.md`](README.speech.md) | Синтез речи (TTS) | Текст → речь |
| [`README.transcription.md`](README.transcription.md) | Транскрипция (STT) | Аудио → текст |

## Что делает `generate.py`

1. Тянет актуальный список **всех** моделей с
   `https://openrouter.ai/api/v1/models?output_modalities=all` — включая генераторы
   изображений/видео/музыки, эмбеддеры, реранкеры, синтез речи и транскрипцию.
2. Сырой ответ API сохраняет в `models_dump.json` (файл в `.gitignore`,
   в репозиторий не попадает).
3. Разбивает модели на категории по модальности **выхода** и генерирует
   отдельный README-файл для каждой категории (см. таблицу выше).
4. Ранжирует модели внутри категории по стоимости вывода (`completion`),
   **кроме** эмбеддеров и реранкеров (у них иная ценовая модель).
   Для TTS/STT ранжирование идёт по цене входа (`prompt`), т.к. стоимость
   исчисляется за токены текста/аудио на входе.


## Непрерывная интеграция (GitHub Actions)

В [`/.github/workflows/weekly.yml`](.github/workflows/weekly.yml) настроен
**еженедельный** запуск (по расписанию, каждый понедельник в 03:00 UTC,
а также ручной через `workflow_dispatch`). Workflow:

1. обновляет окружение Python,
2. запускает `generate.py`,
3. коммитит изменения в категорийные README-файлы и пушит их обратно в репозиторий.
